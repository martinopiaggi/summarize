# Installation

<Tabs>
  <Tab title="PyPI">
    The fastest way to get started:

    ```bash
    pip install martino-summarize
    summarizer --init-config
    echo "GROQ_API_KEY=your_key_here" > .env
    summarizer --source "https://www.youtube.com/watch?v=arj7oStGLkU"
    ```

    Install extras as needed:

    ```bash
    pipx install "martino-summarize[server]"   # HTTP API
    pipx install "martino-summarize[all]"      # server + whisper + litellm
    ```
  </Tab>
  <Tab title="From source">
    ```bash
    git clone https://github.com/martinopiaggi/summarize.git
    cd summarize
    pip install -e .
    ```

    After install, you can also use the console entry point:

    ```bash
    summarizer --source "URL"
    ```

    Or run as a module:

    ```bash
    python -m summarizer --source "https://youtube.com/watch?v=VIDEO_ID"
    ```
  </Tab>
  <Tab title="Streamlit GUI">
    ```bash
    python -m streamlit run app.py
    ```

    Visit `http://localhost:8501`.
  </Tab>
  <Tab title="Docker">
    ```bash
    git clone https://github.com/martinopiaggi/summarize.git
    cd summarize
    cp summarizer.example.yaml summarizer.yaml   # first time only
    echo "GROQ_API_KEY=your_key_here" > .env
    docker compose up -d
    ```

    Open `http://localhost:8501` for the GUI. Summaries are saved to `./summaries/`.

    The CLI and GUI both read the same local `summarizer.yaml`.

    Or pull the pre-built image:

    ```bash
    docker pull ghcr.io/martinopiaggi/summarize:latest
    ```

    CLI via Docker:

    ```bash
    docker compose run --rm summarizer python -m summarizer --source "URL"
    ```

    `docker-compose.yml` mounts `.env`, `summarizer.yaml`, and `./summaries/` for persistence. Cobalt runs as a sidecar for TikTok, Instagram, and other yt-dlp fallbacks.

    See the [Cobalt](integrations/cobalt) page for standalone and proxy setups.
  </Tab>
</Tabs>

## Optional Extras

<AccordionGroup>
  <Accordion title="LiteLLM">
    Route requests through LiteLLM to access 100+ providers with unified calling:

    ```bash
    pip install martino-summarize[litellm]
    ```

    Then set `base_url: litellm` in `summarizer.yaml` and use provider-prefixed models:

    ```yaml
    providers:
      litellm-anthropic:
        base_url: litellm
        model: anthropic/claude-sonnet-4-6
    ```
  </Accordion>
  <Accordion title="Local Whisper">
    ```bash
    pip install martino-summarize[whisper]
    ```

    See [Transcription](features/transcription) for GPU setup.
  </Accordion>
  <Accordion title="HTTP API server">
    Run the summarizer as a local REST API:

    ```bash
    pip install martino-summarize[server]
    summarizer serve
    ```

    Open `http://localhost:8000/docs` for interactive documentation.
    See the [HTTP API guide](api-reference/http-api) for details.
  </Accordion>
  <Accordion title="All extras">
    ```bash
    pip install martino-summarize[all]
    ```
  </Accordion>
</AccordionGroup>

> **Tip:** Install with `pip install martino-summarize[litellm]` to route through LiteLLM and access 100+ providers with unified calling.
